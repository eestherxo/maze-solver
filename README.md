# Maze Solver

An interactive visualization of four search algorithms solving a
fixed maze:

- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- A*
- Greedy Best-First Search


## Requirements

- Python 3.12
- Pygame 2.6.1

Install the project dependency from this directory:

```bash
python3 -m pip install -r requirements.txt
```

## Run the visualization

From the project directory:

For Windows
- ```bash
    python maze_visual.py
    ```

For macOS / Linux
- ```bash
    python3 maze_visual.py
    ```

Choose an algorithm, then click **RUN SEARCH** or press **Space**. Use
**RESET** or press **R** to clear the current animation. Press **Esc** or close
the window to exit


*AI tools were used to assist with debugging and reviewing code*
